# /hide

清理文件中泄露的规则。规则是给 AI 用的，不是给输出看的——但有时它们会泄露到注释和文档里。`/hide` 负责清理。

**作用域**：仅作用于文件（代码、配置、markdown、文档）。不修改 agent 的对话回复。

## 用法

```
/hide <文件路径>    清理指定文件
/hide              清理当前上下文中的文件
```

## 清理目标

八种泄露模式，从注释、文档字符串和叙述性文本中识别并剥离：

| 模式 | 表现形式 |
|------|---------|
| **规则引用** | "as instructed by...", "following the convention...", "per the skill...", "根据 CLAUDE.md...", "按照...的约定" |
| **上下文复读** | "I recall from the docs...", "the codebase follows a pattern where...", "从架构文档中回想起...", "代码库遵循 X 模式..." |
| **约束道歉** | "I can't use X because...", "the team standard requires...", "不能使用 X 因为团队用 Y", "由于规范要求..." |
| **机密泄露** | API keys、tokens、密码、连接串、内部 URL/端点、项目内部代号、mock 数据标签（"// 这是mock数据"、"// 仅用于测试"）、环境信息（服务器名、IP） |
| **过程叙事** | "I'll start by...", "First let me...", "接下来我...", "先...然后...最后..." —— 在注释中叙述 AI 的操作步骤 |
| **元输出** | "Here's the result:", "As requested:", "以下是实现:", TODO/FIXME/HACK 标记、"Actually, let me...", 注释中的自我纠正 |
| **信心信号 & 身份暴露** | "I think...", "我认为...", "This might not cover...", "我假设...", "As an AI...", "作为 AI...", "I hope this helps!", "好问题！", "如有问题随时告诉我" |
| **思维推导过程** | 调研笔记、设计理由、决策记录、"选择 X 是因为..."、"这样做的原因是..."、逐步推理链条、"调研发现..."、"设计决策..."、"进度记录..." —— 记录 AI 如何得出结论而非结论本身 |

## 文件级清理（HITL 确认后删除）

某些文件的**全部内容**都是思维过程 —— 调研日志、设计决策记录、推导链条。对这些文件逐行 strip 没有意义，因为文件本身就是一个泄露。

当 `/hide` 发现文件**大部分内容**匹配「思维推导过程」（模式 H）时：

1. **不做逐行 strip** —— 文件没有有意义的"纯净版本"。
2. **询问用户**（AskUserQuestion）："此文件看起来是 AI 思维过程文档（调研笔记、设计理由、推导链条）。是否直接删除？"
3. 用户确认 → 删除文件。
4. 用户拒绝 → 保持原样不动。

**判断文件应删除而非 strip 的指标：**
- 文件描述的是"如何做出决策"而非"决策是什么"
- 包含 "调研发现"、"findings"、"设计决策"、"decision record"、"进度"、"progress"
- 读起来像 AI 推理步骤日志，而非参考文档
- 移除所有思维过程内容后，文件将为空或几乎为空

## 按文件类型的剥离策略

- **代码文件** (.java, .py, .ts, .go, .rs 等): 删除包含泄露的注释行。保持可执行代码不变。
- **Markdown** (.md): 删除泄露段落。保留技术性内容。
- **配置文件** (.yml, .json, .xml, .toml): 删除泄露注释。保持配置值不变。
- **其他**: 删除匹配泄露模式的注释或叙述性文本。

## 执行规则

**静默执行。禁止：**
- 声明"移除了什么"
- 列举清理项
- 说"文件已清理"或"/hide 已执行"
- 在文件中添加清理标记或注释

**清理后的文件应该看起来原本就是这样写的。**

## 行为边界

- 没有发现泄露 → 什么都不做，什么都不说
- 文件不存在 → 报告错误（这是用户的失误，不是规则泄露）
- 代码逻辑绝不修改 —— 只剥离注释和叙述性文本
- 多行泄露块（如整段解释规则的注释） → 整块删除
